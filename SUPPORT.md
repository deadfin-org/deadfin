# Support

## Where each thing goes

| What | Where |
|---|---|
| A question, setup help, "how do I" | [Discussions](https://github.com/deadfin-org/deadfin/discussions), Q&A |
| An idea to talk through | [Discussions](https://github.com/deadfin-org/deadfin/discussions), Ideas |
| A server bug: something fails, or behaves differently from Jellyfin | [Bug report](https://github.com/deadfin-org/deadfin/issues/new/choose) in deadfin-org/deadfin |
| A client result, pass or fail, from any app, or a playback problem in one app | [Client compatibility report](https://github.com/deadfin-org/deadfin/issues/new/choose) in deadfin-org/deadfin |
| A defect in the deadfin-web app itself | [Issue](https://github.com/deadfin-org/deadfin-web/issues/new) in deadfin-org/deadfin-web. Give the deadfin-web version and the browser. |
| A defect in the SharkParty app itself | [Bug report](https://github.com/deadfin-org/SharkParty/issues/new/choose) in deadfin-org/SharkParty. Give the SharkParty version, the tvOS version and the Apple TV model. |
| A Swiftfin defect that also happens against Jellyfin | [jellyfin/Swiftfin](https://github.com/jellyfin/Swiftfin/issues) |
| An accessibility or language barrier | See [ACCESSIBILITY.md](ACCESSIBILITY.md). Report it in the repository of the app or server where it happens. |
| A feature request | [Feature request](https://github.com/deadfin-org/deadfin/issues/new/choose) in deadfin-org/deadfin |
| A security problem in Deadfin, deadfin-web or SharkParty | [Private vulnerability reporting](https://github.com/deadfin-org/deadfin/security/advisories/new) on deadfin-org/deadfin. See [SECURITY.md](SECURITY.md). |

When you are not sure whether the server or the app is at fault, use the
Client compatibility report.

## Before you ask or report

Read the [FAQ](docs/alpha/faq.md),
[known differences](docs/alpha/known-differences.md) and the
[client matrix](docs/alpha/client-matrix.md). For a bug, follow
[reporting-bugs.md](docs/alpha/reporting-bugs.md): give the image tag, the
client and its version, and the server log near the failure.
